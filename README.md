# MedRoute AI

A Multi-Agent Digital Twin Framework for Autonomous Emergency Medical Logistics and Resource Coordination.

## Problem

Hospitals face delays in obtaining blood, organs, and critical medicines due to poor coordination among blood banks, hospitals, and transport services.

## Solution

MedRoute AI uses:

- Hospital Agent
- Blood Bank Agent
- Transport Agent
- Coordinator Agent
- Digital Twin Dashboard

## Tech Stack

Frontend: React
Backend: FastAPI
Database: PostgreSQL
AI: Scikit-Learn
